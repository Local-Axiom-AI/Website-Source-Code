Privacy & Security

All interactions with AI are designed to protect your confidentiality and anonymity. The following safeguards are in place:

  • Session-based rate limiting: Each session is identified by a unique random string; rate limits are applied per session, not per IP.
  • Ephemeral storage: Chat data resides only in RAM and is purged automatically every hour.
  • Anonymous chat IDs: Each conversation is linked to a random, non-traceable chat ID.
  • Strong encryption: All messages are encrypted with AES-256, preventing any third party from reading content.
  • Dedicated infrastructure: Computation occurs on servers that we own and operate within our own facility.

Accounts & Authentication

Our platform uses a 64-digit account number as the sole identifier for your user profile. No usernames or passwords are required. This number is generated with cryptographicly secure means. The number is not tied only to this version of the site, it does transfer to I2P and TOR versions of the site; keep the number confidential to maintain security.

Signing in is totaly optional, but we encourage it because it allows the use of smarter models. We made Qwen-3 30B-a3B the default for non signed in users because that model is now using VLLM for many concurent requests compared to the other models sequential requests.
